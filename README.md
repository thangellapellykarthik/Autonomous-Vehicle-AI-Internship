# AI-Based Autonomous Vehicle System

## Internship
AI Research Internship – National Institute of Technology (NIT) Warangal

## Project Overview
This project focuses on developing an AI-based autonomous robotic vehicle for campus navigation and monitoring.

## Key Features
- Autonomous navigation from point A to point B
- Obstacle detection and avoidance
- Road and traffic monitoring
- Parking and no-parking zone monitoring
- Vehicle detection and number plate recognition
- Camera-based visual monitoring

## Technologies Used
- Python
- OpenCV
- YOLO-based object detection
- Arduino
- Computer Vision
- Machine Learning
